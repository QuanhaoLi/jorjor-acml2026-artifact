# Camera-Ready Rebuttal Evidence

This directory preserves the frozen k.8 five-run and k.9 exact-posterior reports plus a minimal source snapshot for auditability.

- `source_reports/`: frozen scientific reports and paper replacement notes.
- `code/`: five-run aggregation, posterior construction/readout, support-repair, and run entry points.

The raw remote archives are intentionally excluded because they contain multi-gigabyte checkpoints and pair arrays. Their published product checksums are recorded in `../CAMERA_READY_REBUTTAL_ADDENDUM.md`.
